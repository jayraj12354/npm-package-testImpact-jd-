How TestImpact-JD Works

A deterministic 4-stage pipeline built on AST analysis and reverse graph traversal.

1

Git Inspection

Executes safe Git subprocesses to detect modified, added, deleted, renamed, or untracked files across your working tree or branch comparison.

2

AST Graph Construction

Parses ES imports, re-exports, CommonJS, and tsconfig path aliases via TypeScript Compiler API to build forward & reverse adjacency maps.

3

Reverse Traversal

Breadth-first search traverses from changed files backwards through dependents, calculating dependency distances and cycle-safe visited sets.

4

Selective Execution

Prioritizes tests (direct changes first, then transitive distance) and delegates execution to Vitest or Jest, streaming results & preserving exit codes.

Documentation & Quick Reference

Everything you need to configure and use TestImpact-JD in your projects.

CLI Commands

npx testimpact-jd init
Auto-detects runner & language, generates testimpact.config.ts
npx testimpact-jd run
Analyzes Git changes and executes affected tests
npx testimpact-jd run --staged
Analyzes only staged changes (pre-commit hook friendly)
npx testimpact-jd run --base main
Compares against base branch for PR checks in CI/CD
npx testimpact-jd analyze --json
Outputs structured JSON report without running test runners

Configuration (`testimpact.config.ts`) 

import { defineConfig } from 'testimpact-jd';

export default defineConfig({
  testRunner: 'auto', // 'auto' | 'vitest' | 'jest'

  source: {
    include: ['src/**/*'],
    exclude: ['**/node_modules/**', '**/dist/**'],
  },

  tests: {
    include: ['**/*.test.ts', '**/*.spec.ts'],
    exclude: ['**/node_modules/**'],
  },

  git: {
    baseBranch: 'auto',
    untracked: true,
  },

  analysis: {
    transitiveDependencies: true,
    conservativeMode: true,
  },

  fallback: {
    runAllOnAnalysisError: true,
  },
});
